# Java Assignment 3 – All Question Code

Each task folder contains a standalone Java source file.

## Requirements
- JDK 11 or later (JDK 17 recommended)
- Terminal / Command Prompt

## Compile and run
Open a terminal in the relevant task folder.

- Task01: `javac ATMExample.java` then `java ATMExample`
  - Create an empty `card-reader.txt` in the same folder before running the valid-input path.
- Task02: `javac StorageDemo.java` then `java StorageDemo`
- Task03: `javac SalesReport.java` then `java SalesReport store1.txt store2.txt`
  - Each input file should contain one sales amount per line.
- Task04: `javac ScannerDemo.java` then `java ScannerDemo`
- Task05: `javac SeatBooking.java` then `java SeatBooking`
- Task06: `javac TokenCounter.java` then `java TokenCounter`
- Task07: `javac ResultProcessor.java` then `java ResultProcessor 4 scores`
  - Create a `scores` folder containing text files with marks from 0 to 100.
  - To measure pool sizes, run with 1, 2, 4 and 8 instead of 4.

Run every task yourself and capture actual output screenshots. Record real timing results and thread completion orders; do not invent measurements. Both partners must independently execute every task according to the assignment instructions.
